# Calculator

A menu-driven calculator written in C as part of my B.Tech CSE programming practice.

## Features

- Addition, subtraction, multiplication, and division
- Square root and power calculations
- Factorial and percentage calculations
- Trigonometric functions: sin, cos, tan, sec, cosec, and cot
- Basic checks for division by zero and invalid square-root/factorial inputs

## Requirements

- A C compiler
- The math library (`math.h`)

## Compile and run

On GCC, compile with:

```bash
gcc main.c -o calculator -lm
./calculator
```

This is an educational project and will be improved as I continue learning C.
